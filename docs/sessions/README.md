# Карточки сессий

Одна сессия — один файл `ГГГГ-ММ-ДД-модель.md`. Карточка короткая: чтобы следующая модель за минуту поняла, что происходило и где искать детали.

## Шаблон

```md
# Сессия 2026-10-23 — DeepSeek

- Ветка/коммит: experiment / <hash>
- Цель сессии: одна строка
- Что сделано: 3–6 пунктов
- Решения: ссылки на docs/DECISIONS.md (или новые)
- Ошибки: ссылки на docs/ERRORS.md (или новые)
- Проверки: что и как проверяли, где скриншоты
- Что осталось: следующий шаг
- Где полная переписка: путь/ассет
```

## Правила

- Пишет сама модель в конце сессии, честно: что не получилось — тоже.
- Не дублировать `TODO.md`: здесь — обзор, там — подробности.
- Если сессия была только «поговорить», всё равно карточка: о чём договорились.
- Файлы не удалять и не переписывать задним числом.
