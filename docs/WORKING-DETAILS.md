# Рабочие подробности

> ⚠️ Здесь и в перечисленных файлах есть **рабочие подробности**: пути на моём ПК, названия папок, карточки сессий, переписка. Я работаю над проектом один и никому ссылку на репозиторий не давал. Если репозиторий станет публичным — эти вещи можно удалить или заменить.

## Что считается рабочими подробностями

| Файл / папка | Что внутри | Как убрать |
|---|---|---|
| `docs/DEV.md` | путь `C:\tapyor-player`, особенности моего ПК, ловушки запуска | заменить путь на `<папка проекта>`, убрать личные детали |
| `docs/CURRENT.md` | кто работал, где лежит «палочка» | переписать под текущую модель |
| `docs/sessions/` | карточки сессий: даты, модели, что делали | удалить папку целиком |
| `docs/BRIEF-OPUS.md` | бриф с локальными путями | удалить, если не нужен |
| `history/` | переписка: краткая, средняя, полная | удалить папку целиком |
| `docs/ERRORS.md` | примеры с путями и переменными окружения | оставить: полезно, но можно вычистить пути |
| `docs/audits/` | отчёты аудитов | удалить старые, если мешают |

## Как удалить одной командой (потом, с нейросетью)

Попросить модель:

> Удали рабочие подробности из репозитория: папку `history/`, папку `docs/sessions/`, файл `docs/BRIEF-OPUS.md`; в `docs/DEV.md` замени путь `C:\tapyor-player` на `<папка проекта>`; в `docs/CURRENT.md` и `docs/ERRORS.md` убери личные пути. Ничего не публикуй без моей команды.

Или вручную:

```powershell
Remove-Item history -Recurse -Force
Remove-Item docs\sessions -Recurse -Force
Remove-Item docs\BRIEF-OPUS.md -Force
```

После удаления сделай коммит. История git всё равно хранит старые версии — если нужно вычистить и её, это отдельная операция (перезапись истории), её делаем только по явной команде.

## Что НЕ является рабочими подробностями

`docs/DECISIONS.md`, `docs/ERRORS.md` (суть), `docs/HANDOFF.md`, `docs/AUDIT.md`, `docs/releases/`, `TODO.md` — это полезная документация проекта, её лучше оставить.
