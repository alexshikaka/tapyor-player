## Варианты выдачи поиска (0.11, `src/rank.js`)

| Вариант | Что первым |
| --- | --- |
| Умный (по умолчанию) | Точность + бонус площадке с полным доступом (Яндекс с Плюсом выше всех) |
| По точности | Только совпадение названия/исполнителя с запросом |
| Сначала мои подписки | Яндекс с Плюсом, YouTube со входом; отрывки вниз |
| Сначала бесплатные | SoundCloud, Audius, YouTube; Яндекс ниже |
| Для эфира | Студийные версии целиком; клипы, лайвы, >10 мин, отрывки — вниз |
| По площадкам | Разделами в порядке `srcOrder` |

Точность: полное совпадение названия > начинается с > содержит; бонус за совпавшего исполнителя; штраф за remix/cover/live/karaoke/slowed/реакции, если их нет в запросе; бонус официальным каналам YouTube (Topic, VEVO); популярность — только чтобы развести равные. Одна песня с разных площадок склеивается (`songKey`), остальные — «+N версии».

## Известные подводные камни

- `crossOrigin` / Web Audio на `<audio>` ломают потоки Яндекса — не возвращать.
- В облачной сессии нет npm-реестра и GraphQL GitHub; YouTube/Яндекс из облака недоступны — проверять через моки и логи владельца.
- Playwright-Chromium не умеет AAC в MSE — тестовый HLS на mp3.
- `window.prompt` в Electron не работает — использовать `askDlg` в `index.html`.
- Рецепты (`recipes.json`) берутся с GitHub `main` всеми пользователями сразу — править аккуратно, поднимать `version`, проверять `minApp`.
