# Журнал решений (ADR)

Формат: **контекст → варианты → выбрали → почему → последствия**. Отменённые решения не удаляются, а помечаются.

## 2026-10-23. Окно масштаба — отдельное окно, а не поповер в странице

- **Контекст:** поповер жил в DOM плеера, масштабировался вместе с интерфейсом и дёргался при каждом шаге ползунка.
- **Варианты:** (1) оставить в странице и компенсировать `transform: scale(1/zoom)`; (2) отдельный `BrowserWindow`; (3) системный диалог.
- **Выбрали:** отдельный `BrowserWindow` (`src/zoom.html` + `src/zoom-preload.js`), 300×208, всегда 100 %.
- **Почему:** окно не входит в раскладку, не зависит от zoom, может жить в своей теме.
- **Последствия:** тема передаётся в адресе окна (`?t=base64`); окно пересоздаётся при каждом открытии, показывается после `ready-to-show` с `opacity 0→1`; повторный клик закрывает.

## 2026-10-23. Подсказки — один fixed-элемент `.tip`

- **Контекст:** нативные `title` выглядели по-разному; псевдоэлемент `[data-tip]::after` требовал `position: relative` и ломал раскладку подвала.
- **Варианты:** (1) псевдоэлементы; (2) один общий fixed-элемент; (3) сторонняя библиотека.
- **Выбрали:** один `.tip`, задержка 600 мс, одна строка, автопереворот у кромок; для перемотки — режим следования за курсором.
- **Почему:** не участвует в раскладке, не обрезается контейнерами, единый вид.
- **Последствия:** `title` конвертируется в `data-tip` (MutationObserver + обход); нельзя возвращать `[data-tip] { position: relative }`.

## 2026-10-22. Оболочки — только покраска

- **Контекст:** пиксельные скины (Гамебой, Аркада, DOS, Неон-скан) и «Афиша» с другим принципом.
- **Выбрали:** скин меняет только CSS-переменные/шрифт/радиусы, но не раскладку и не поведение.
- **Почему:** иначе каждая оболочка ломает очередь, подвал, шапку и требует отдельного тестирования.
- **Последствия:** аудит `tests/skins/audit.js`; строгие проверки — для пиксельных, мягкий режим — для новых принципов. Scorched Earth и Winamp отвергнуты и удалены.

## 2026-10-21. Локальная разработка вместо сборки в облаке

- **Контекст:** установщик собирался на GitHub Actions, а проверить интерфейс вживую было нельзя.
- **Выбрали:** запуск из исходников через `node_modules\electron\dist\electron.exe` + CDP 9222 + Playwright; релиз — только по команде.
- **Почему:** быстрый цикл правок и проверок, скриншоты, отсутствие случайных публикаций.
- **Последствия:** см. `docs/DEV.md` (три ловушки) и `docs/ERRORS.md`.

## 2026-10-23. Релиз — только по явной команде владельца

- **Контекст:** версия 0.19.0 опубликована; 0.19.1 обсуждалась, но команды не было.
- **Выбрали:** не менять версию, не собирать установщик и не пушить теги без явного «делай релиз».
- **Последствия:** вся работа 23.10 осталась локально в ветке `experiment`; при релизе — снимок `docs/releases/vX.Y.Z/`.
