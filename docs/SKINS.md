# Оболочки: как устроены, как добавить новую

Документ для того, кто продолжит проект (в том числе для Claude Code по репозиторию). Здесь: принципы, переменные, цветовые схемы, правила построения и порядок добавления новой оболочки.

---

## 1. Что такое оболочка

Оболочка (skin) — это оформление всего интерфейса поверх цветовой темы: свои цвета, шрифт, форма рамок и кнопок. Она включается классом на `<html>`:

```
html.pixel-skin.skin-dos     — пиксельная оболочка VGA / DOS
html.pixel-skin.skin-crt     — пиксельная CRT (Неон-скан)
html.pixel-skin.skin-retro   — пиксельная «Ретро-десктоп»
html.skin-afisha             — «Афиша» (стекло, без пиксельного класса)
```

Пиксельные оболочки получают класс `pixel-skin`, который:
- обнуляет все скругления (`html.pixel-skin * { border-radius: 0 !important; }`);
- включает пиксельный шрифт (`Pixelify Sans` / `Press Start 2P`);
- включает строгие проверки аудита (см. §6).

Оболочки нового принципа (например, стеклянная «Афиша») класс `pixel-skin` **не** получают: у них свои радиусы, свой шрифт и мягкие проверки.

Признак хранится в данных оболочки:

```js
var SKINS = [
  { id: 'dos',    name: 'VGA / DOS', ..., pixel: true  },
  { id: 'crt',    name: 'Неон-скан', ..., pixel: true  },
  { id: 'retro',  name: 'Ретро-десктоп', ..., pixel: true },
  { id: 'afisha', name: 'Афиша', ..., pixel: false }   // стекло
];
```

Применение — `applySkin(id, save)`:

1. снять старые классы и инлайновые переменные (`clearSkinClass()`, `clearSkinVars()`);
2. добавить `skin-<id>` и, если `pixel !== false`, `pixel-skin`;
3. наложить переменные цветовой схемы (`applySkinVars(id)`, см. §3);
4. сохранить выбор (`localStorage.tapSkin` + настройка `skin`).

## 2. Переменные, из которых собирается оболочка

Оболочка задаёт не «цвета элементов», а набор CSS-переменных. Их читает вся вёрстка.

| Переменная | Смысл | Как выводится из ядра |
|---|---|---|
| `--bg00` | самый тёмный фон (подложка окна) | `mix(bg, #000, 0.32)` для тёмных, `0.10` для светлых |
| `--bg0` | фон приложения | `bg` |
| `--bg1` | панели (шапка, подвал, карточки) | `panel` |
| `--bg2` | поверхности (строки, чипсы) | `surface` |
| `--bg3`, `--bg4` | наведение, вложенные блоки | `mix(surface, text, 0.07 / 0.14)` |
| `--ln` | границы | `line` |
| `--ln2`, `--ln3` | границы тише / ярче | `mix(line, bg, 0.45)` / `mix(line, text, 0.30)` |
| `--tx` | основной текст | `text` |
| `--tx2..--tx5` | текст слабее | ступени `mix(text, bg, 0.16 / 0.32 / 0.48 / 0.62)` |
| `--ac`, `--ac2` | акцент и акцент при наведении | `accent`, `mix(accent, #fff, 0.28)` |
| `--acr`, `--acbg` | акцент как `r,g,b` и его подложка | из `accent` |
| `--pri`, `--prit` | главная кнопка и текст на ней | `button`, контрастный текст |
| `--hov` | подсветка при наведении | тёмная/светлая вуаль |

Правила простые и общие для всех оболочек: **фоновые оттенки смешиваются с фоном, текст — ступени от основного к фону, акцент даёт свою пару**. Это позволяет любой оболочке работать с любой схемой без ручной правки.

Плюс структурные токены (не цвета): `--r-panel`, `--r-card`, `--r-ctl`, `--r-tab` (радиусы), шрифт задаётся правилами `html.skin-<id>`.

## 3. Цветовые схемы (4 на оболочку + «СВОЯ»)

У каждой оболочки есть **ядро из 7 основных цветов**:

```
Фон · Панели · Поверхности · Границы · Текст · Акцент · Кнопки
```

И **четыре готовые схемы**; пятое состояние — «СВОЯ», когда любой цвет поправлен руками.

Данные (в `src/index.html`, сразу после `SKINS`):

```js
var SKIN_SCHEMES = {
  afisha: [
    { id: 'red',     name: 'Красная афиша', core: { bg: '#1A0705', panel: '#2A0D0A', surface: '#351210', line: '#5A1D18', text: '#F6EDEA', accent: '#E04A4A', button: '#E04A4A' } },
    { id: 'blue',    name: 'Синяя ночь',    core: { ... } },
    { id: 'emerald', name: 'Изумруд',       core: { ... } },
    { id: 'amber',   name: 'Янтарь',        core: { ... } }
  ],
  dos: [ ... ], crt: [ ... ], retro: [ ... ]
};
```

Схемы по оболочкам (полный список — в коде):

| Оболочка | Схемы |
|---|---|
| VGA / DOS | Классика VGA, Нортон, Янтарь, Турбо-синий |
| Неон-скан | Неон, Зелёный фосфор, Янтарный ЭЛТ, Синий ЭЛТ |
| Ретро-десктоп | Графит, Win 95, Слива, Олива |
| Афиша | Красная афиша, Синяя ночь, Изумруд, Янтарь |

### Состояния и хранение

- `curSkinScheme[skinId]` — id схемы или `'custom'`;
- `curSkinCore[skinId]` — ядро, когда схема «СВОЯ»;
- сохранение: настройка `skinSchemes` и `localStorage.tapSkinSchemes` в виде
  `{ "afisha": { "id": "custom", "core": { ... } }, "dos": { "id": "amber" } }`;
- при старте `loadSkinSchemes()` вызывается **до** `applySkin()`, чтобы переменные встали сразу.

### Функции (все в `src/index.html`)

| Функция | Что делает |
|---|---|
| `skinVarsFromCore(core)` | ядро → полный набор CSS-переменных |
| `applySkinVars(id)` | наложить переменные схемы оболочки инлайном на `<html>` |
| `clearSkinVars()` | снять их при выключении оболочки |
| `setSkinScheme(id, sid, save)` | выбрать готовую схему |
| `setSkinCoreColor(id, key, hex)` | изменить один основной цвет → схема становится «СВОЯ» |
| `resetSkinScheme(id)` | вернуться к первой схеме |
| `renderSkinScheme()` | отрисовать блок схемы в настройках |

Инлайн-переменные важны: они перебивают и правила оболочки, и цветовую тему, поэтому «СВОЯ» применяется мгновенно.

### Где это в интерфейсе

«Настройки → Оформление»: карточки оболочек (`#skinGrid`), под ними ползунки (`#skinAdjRow`) и блок **«Цветовая схема»** (`#skinSchemeRow`) — выпадающий список схем и семь образцов основных цветов с HEX. Клик по образцу открывает общее окно выбора цвета (`colOpenFor`), там же пипетка на весь экран (`A.pickColor()`).

## 4. Как добавить новую оболочку

1. **Данные.** Добавить запись в `SKINS`: `id`, `name`, `sub`, `tag`, четыре цвета для превью (`bg`, `card`, `line`, `txt`, `btn`) и `pixel: true|false`.
2. **CSS.** Добавить блок `html.skin-<id> { --r-*: ...; }` и правила `html.skin-<id> .card, ...` — только структура (радиусы, тени, стекло, фаски). Цвета — из переменных (`var(--bg1)`, `var(--ac)`, …), не хардкодом.
3. **Схемы.** Добавить 4 схемы в `SKIN_SCHEMES[<id>]`, у каждой 7 цветов ядра. Первая схема — «как в референсе».
4. **Пиксельный класс.** Если оболочка не пиксельная — `pixel: false` и не полагаться на `pixel-skin` (шрифт задать своим правилом).
5. **Аудит.** `npm run audit:skins` — для не-пиксельных оболочек строгие проверки пропускаются автоматически.
6. **Документация.** Дописать строку в таблицу схем и, если принцип новый, — раздел в этом файле.

### Чек-лист новой оболочки

- [ ] видна в списке, карточка с превью и тегом;
- [ ] включается/выключается, возвращает цветовую тему при выключении;
- [ ] 4 схемы + «СВОЯ», выбор сохраняется и переживает перезапуск;
- [ ] все 4 схемы читаемы: текст на поверхностях, кнопки с контрастным текстом;
- [ ] работает на всех пяти вкладках и в настройках;
- [ ] `npm run audit:skins` без ошибок.

## 5. Пример: оболочка «Афиша» (по референсу)

Референс: тёмно-красный музыкальный плеер с большой фотографией артиста, стеклянным поиском, скруглёнными карточками и красной кнопкой Play.

Перенос на наш интерфейс:

| В референсе | У нас |
|---|---|
| тёмно-красный градиент фона | `.app-shell` с `radial-gradient` из `--bg2/--bg1/--bg0/--bg00` |
| стеклянные панели и списки | `.card, .queue-col, .searchbar, .set-main` — `rgba(255,255,255,.045)` + `backdrop-filter: blur(14px)` + рамка `rgba(255,255,255,.09)` |
| крупные скругления | `--r-panel: 22px`, `--r-card: 18px`, `--r-ctl: 12px`; у контейнера скруглён только низ |
| красная кнопка Play и «Play all» | `.cbtn.play`, `.pbtn.y` — фон `var(--pri)`, белый текст, мягкая тень |
| капсульные кнопки | `.pbtn, .rq-sm, .chip` — `border-radius: 999px` |
| прозрачный подвал | `footer` — прозрачный, только верхняя линия |
| крупные обложки со скруглением | `.art-n img, .cov, .q-art img` — `border-radius: 14px` |

Схемы «Афиши»: **Красная афиша** (референс), **Синяя ночь**, **Изумруд**, **Янтарь**. Те же правила, что у остальных: ядро → переменные.

## 6. Аудит оболочек

`npm run audit:skins` (или `node tests/skins/audit.js`) открывает приложение в браузере, включает каждую оболочку, проходит все вкладки и ищет «выпавшие» элементы.

Проверки и их смысл:

| Проверка | Для каких оболочек | Что значит находка |
|---|---|---|
| УГЛЫ | пиксельные | радиус > 0 там, где должна быть фаска |
| ШРИФТ | пиксельные | текст не шрифтом оболочки |
| ХРОМ | пиксельные | панель с заливкой без фаски/ореола |
| ПАЛИТРА | пиксельные | плотная заливка не из цветов оболочки |

Для оболочек с `pixel: false` строгие проверки не применяются — у них другой принцип (стекло, градиенты, крупные радиусы). Аудит всё равно печатает их в отчёте, чтобы видеть список.

Коды выхода: `0` — ошибок нет, `1` — есть ошибки в пиксельных оболочках.

## 7. Что помнить при доработках

- Цвета в правилах оболочки — **только через переменные**, иначе схема «СВОЯ» не подействует.
- Инлайновые переменные схемы перебивают CSS, поэтому при выключении оболочки их обязательно снимать (`clearSkinVars`).
- Пиксельные оболочки форсируют шрифт и обнуляют радиусы — не полагайтесь на них для новых принципов.
- Светлая схема (например, «Win 95» в «Ретро-десктопе») должна иметь тёмный текст: контраст кнопок считается по luminance текста.
- Новые схемы добавляются только данными — код менять не нужно.

## 8. Идеология схем: что символизирует каждая

Схемы — не «набор красивых цветов», а отсылка к конкретной эпохе и её логике. Ниже — что взято за основу.

### VGA / DOS

| Схема | Символ | Откуда цвета |
|---|---|---|
| **Norton Commander** | двухпанельный файловый менеджер DOS | синие панели и циановые подписи NC ([описание палитры NC](http://annex.retroarchive.org/cdrom/nightowl-008/018A/NCU3/README.TXT)) |
| **Turbo Pascal** | первый рабочий экран программиста | тёмно-синий IDE, жёлтые подсказки, бирюзовое меню |
| **Янтарный монитор** | P3-фосфор, монохромные терминалы | чёрный + янтарь `#FFB000` |
| **BBS / ANSI** | доски объявлений и ANSI-арт | чёрный фон, циан и маджента из ANSI-палитры |

### Неон-скан (CRT)

| Схема | Символ | Откуда цвета |
|---|---|---|
| **P1 · зелёный фосфор** | терминал ЦУП, зелёный монохром | зелёный P1 `#33FF99` |
| **P3 · янтарь** | медицинские и военные мониторы | янтарь `#FFAE33` на тёмно-коричневом |
| **VHS** | выцветшая кассета, домашнее видео | кремовый, пыльный голубой, розовая полоса |
| **Неон-вывеска** | ночной город, синтвейв | маджента + циан на почти чёрном ([ретро-палитры 80-х](https://filmora.wondershare.com.br/video-creative-tips/retro-80s-color-palette.html)) |

### Ретро-десктоп

| Схема | Символ | Откуда цвета |
|---|---|---|
| **Windows 95** | бирюзовый рабочий стол и платина панелей | teal `#008080`, платина `#C0C0C0`, тёмно-синий заголовок ([Win95 teal](https://zh.spycolor.com/0808e1)) |
| **Mac OS Platinum** | интерфейс Apple 8–9 | серый «платиновый» корпус, синий акцент ([Appearance Manager](https://en.wikipedia.org/wiki/Appearance_Manager)) |
| **BeOS** | система, опередившая время | синие окна и жёлтая полоса BeOS R5 |
| **Motif / CDE** | Unix-рабочие станции | пыльный сланец, серый металл, оранжевый акцент |

### Афиша

| Схема | Символ | Откуда цвета |
|---|---|---|
| **Концертный постер** | шелкография афиш 60-х | кремовая бумага, красный, чёрный ([плакатная типографика](https://creativepro.com/classic-concert-posters-reimagined/)) |
| **Винил** | конверт пластинки | матовый чёрный картон, кремовый шрифт, оранжевая наклейка лейбла |
| **Ночной клуб** | тёмный зал, лазеры | кислотный лайм и циан |
| **Красная афиша** | сцена и бархат референса | тёмно-красный градиент, красный акцент |

У каждой схемы в данных есть поле `desc` — короткое объяснение символа. Оно показывается в настройках под списком схем, поэтому идеология видна прямо в интерфейсе.

## 9. Дизайн «Афиши»: не перекраска, а другая вёрстка

«Афиша» отличается от остальных оболочек **структурой**, а не только цветом:

| Приём | Что делает |
|---|---|
| Сетка карточек в выдаче | `.tarea > div` становится grid, трек — карточкой с обложкой 1:1, а не строкой списка |
| Крупные обложки | `cover-wrap` растянут на всю ширину карточки, `aspect-ratio: 1/1` |
| Полки плейлистов | `.pls` — grid с переносом, а не горизонтальная лента |
| Плавающий подвал | `footer` — капсула с отступами, стеклом и тенью |
| Постерные заголовки | крупный вес и отрицательный трекинг у заголовков |
| Капсульная навигация | вкладки-пилюли, активная — со светлой подложкой |
| Стеклянные панели | `rgba(255,255,255,.05)` + `backdrop-filter: blur(16px)` |

Поэтому «Афиша» — первый пример оболочки **другого принципа** (`pixel: false`), и на ней проверена вся система схем: 4 идеологии + «СВОЯ», всё на одних и тех же переменных.
### 9.1 Стекло и воздух (обновление)

Опора на актуальные тренды интерфейсов: **glassmorphism 2.0** — многослойное стекло, светлая кромка, тихая зернистость ([разбор принципов](https://github.com/valdsab/open-design/blob/main/design-systems/glassmorphism/DESIGN.md)), «liquid glass» с глубиной и подсветкой ([обзор Apple OS 26](https://www.macstories.net/stories/wading-back-into-the-liquid-glass-pool-the-macstories-os-26-app-roundup-continued/)), аврора-градиенты и bento-сетки ([каталог стилей](https://github.com/maddhruv/absolute/blob/HEAD/skills/absolute-ui/references/style-catalog.md)).

Что применено в «Афише»:

- **Фон**: три радиальных «сияния» из цветов схемы + очень тихая SVG-зернистость (`feTurbulence`, `mix-blend-mode: soft-light`) — фон не плоский, но и не шумный.
- **Стекло в два слоя**: градиент `rgba(255,255,255,.10 → .035)` + `backdrop-filter: blur(22px) saturate(140%)`, светлая кромка `inset 0 1px 0`, мягкая тень `0 22px 48px`.
- **Воздух между зонами**: шапка, контент, очередь и подвал разведены отступами 16–18 px; панели не примыкают друг к другу и к краям окна.
- **Карточки-плитки**: выдача — сетка, трек — карточка с обложкой 1:1; плейлисты — крупные альбомные карточки, а не строки.
- **Микроанимации**: подъём карточки на 3–4 px и подсветка акцентом при наведении, плавные переходы 160–180 мс.
- **Плавающий подвал**: капсула со стеклом, тенью и зазором от рабочей области.

Проверено замерами: обложка карточки 184×184, карточка 206 px, карточка плейлиста 190 px (обложка 168×168), зазор «контент → подвал» 6 px, фон подвала `backdrop-filter: blur(24px) saturate(1.4)`.
