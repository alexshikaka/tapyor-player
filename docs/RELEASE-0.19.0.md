# Тапёр 0.19.0 — панель для OBS, схемы Yami и новые оформления

## Панель заказов для OBS

Отдельная страница `http://127.0.0.1:47654/widget`, открывается в OBS как док-панель: «Вид» → «Панели» → «Пользовательские панели браузера».

- Лента сообщений — один-в-один как во вкладке «Заказы»: имя, сумма, текст, найденный трек, обложка, статус.
- Все кнопки работают прямо из панели: «＋ В очередь», «Сейчас», «Другие варианты», «Искать сам», «Не то», «Это заказ — искать».
- «Искать сам» и «Это заказ — искать» открывают Тапёр поверх остальных окон и ставят курсор в строку поиска.
- Внизу мини-плеер (назад, пауза, следующий, время) и кнопка поиска справа — тоже поднимает плеер.
- Индикатор связи сверху: зелёный «Подключён», красный «Отключён», если программа закрыта.
- Оформление: как в текущей теме, конкретная оболочка, конкретная тема или шесть схем Yami.
- Yami-схемы: Default, Acri, Classic, Grey, Light, Rachni — со шрифтом OBS (Segoe UI) и прямыми углами, как панели OBS.
- Рядом с выбором — образцы цветов с HEX, клик копирует код.
- Масштаб 60–160 %, настройка «Новые сообщения: сверху/снизу».
- Постоянный адрес: порт меняется в настройках («OBS и стрим → Порт»), по умолчанию 47654.

## Оформление

- Три оболочки: VGA / DOS, Неон-скан, Ретро-десктоп; ползунки яркости, насыщенности, контраста; наборы шрифтов.
- Встроенная светлая тема.
- Монохромные логотипы источников, актуальный знак Яндекса (вспышка).
- Аудит оболочек: `npm run audit:skins`.

## Порядок и мелочи

- «Точные — сразу в очередь» синхронизирован в трёх местах: вкладка «Заказы», настройки OBS, панель.
- Зазор между сообщениями в ленте — 14 px.
- Разделы «OBS и стрим» и «Стримерам» перенесены вниз, порядок меню совпадает с порядком разделов.
- Локальные файлы отдаются без кэша — после обновления не показывается старая страница.
