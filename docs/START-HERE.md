# Начни отсюда

Этот файл — точка входа для **любой** модели, которая продолжает проект «Тапёр»: Claude Code, DeepSeek, кто угодно. Прочитай его первым, дальше — по списку.

## Если ты модель

1. `docs/CURRENT.md` — что происходит сейчас: кто работал последним, на чём остановились, что дальше.
2. `docs/HANDOFF.md` — состояние проекта и карта кода.
3. `docs/DEV.md` — как запустить на ПК владельца (там же три ловушки).
4. `docs/DECISIONS.md` — почему сделано именно так.
5. `docs/ERRORS.md` — где уже набиты шишки.
6. Последний снимок релиза: `docs/releases/INDEX.md` → папка версии.
7. `docs/sessions/` — карточки прошлых сессий: кто, что, чем закончил.
8. И только потом — код.

Правила проекта: работаем локально; релиз только по явной команде владельца; `appId` не менять; скины только «красят», не меняют раскладку; владелец не программист — объяснять простыми словами и показывать скриншоты.

## Если ты владелец

Просто скажи новой модели:

> Привет. Мы работали над «Тапёром» с другой моделью. Прочитай `docs/START-HERE.md` и всё, на что он ссылается, чтобы войти в курс. Ничего не публикуй и не меняй версию без моей команды.

Больше ничего передавать не нужно: репозиторий сам содержит историю.

## Что модель обязана сделать в конце своей сессии

1. Заполнить `docs/CURRENT.md`: дата, что сделано, что дальше, открытые вопросы.
2. Добавить карточку `docs/sessions/ГГГГ-ММ-ДД-модель.md` по шаблону из `docs/sessions/README.md`.
3. Дописать `TODO.md` (что и почему) и, если были решения/ошибки, — `docs/DECISIONS.md` / `docs/ERRORS.md`.
4. Если менялся способ запуска — обновить `docs/DEV.md`.
5. Полную переписку — в ассеты релиза или в `docs/sessions/` дайджестом; не в git целиком.

Так «палочка» переходит от модели к модели без потерь.
