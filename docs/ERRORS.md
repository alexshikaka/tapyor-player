# Грабли и их лечение

Симптом → причина → лечение → как не повторить. Пополняется сразу после инцидента.

## Electron не запускается: `ELECTRON_RUN_AS_NODE`

- **Симптом:** приложение молчит или ведёт себя как Node-скрипт, окно не появляется.
- **Причина:** в окружении выставлена переменная `ELECTRON_RUN_AS_NODE=1` (остаётся от других инструментов).
- **Лечение:** `Remove-Item Env:\ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue` перед запуском.
- **Не повторять:** запускать только через ярлык или команду из `docs/DEV.md`.

## Electron падает молча из-за прав папки

- **Симптом:** процесс стартует и сразу завершается, без ошибки.
- **Причина:** у папки проекта «запрещающие» права (после распаковки/синхронизации).
- **Лечение:** см. `docs/DEV.md`, раздел «Три ловушки».
- **Не повторять:** не распаковывать проект в системные папки; проверять права после переноса.

## Подвал «уехал» после унификации подсказок

- **Симптом:** кнопки play/прогресс/громкость сместились, окно прокручивается.
- **Причина:** правило `[data-tip] { position: relative }` повесилось на все элементы с подсказкой; абсолютные дети получили другого родителя.
- **Лечение:** убрать `position: relative` у `[data-tip]`, рисовать подсказку отдельным fixed-элементом.
- **Не повторять:** не стилизовать контейнеры подсказок так, чтобы менялась геометрия.

## Подсказки стали переноситься на две строки и «прыгать»

- **Симптом:** длинный текст ломал вид и позицию.
- **Причина:** `white-space: normal` + `max-width` у псевдоэлемента.
- **Лечение:** `white-space: nowrap`, ширина по тексту, позиция с ограничением по краям экрана.
- **Не повторять:** переносы в подсказках не включать.

## `revealZoomWindow is not defined` в главном процессе

- **Симптом:** диалог «A JavaScript error occurred in the main process» при клике по «Масштаб».
- **Причина:** при переписывании `showZoomWindow` функция показа была случайно удалена, а таймер и IPC её вызывали.
- **Лечение:** вернуть функцию, проверить `node --check src/main.js`.
- **Не повторять:** после переписывания блока искать все ссылки на удалённые функции: `grep -n "functionName" src/main.js`.

## Мигание окна масштаба при смене темы

- **Симптом:** окно открывалось в стандартной теме, затем перекрашивалось.
- **Причина:** показ до применения темы; скрытое окно хранило старый кадр.
- **Лечение:** тема в адресе (`?t=base64`), пересоздание окна при каждом открытии, показ после `ready-to-show` с `opacity 0→1`, повторный клик закрывает.
- **Не повторять:** не показывать окно до готовности темы и не перезагружать видимое окно.

## Правка `index.html` по номерам строк ломает файл

- **Симптом:** дубли функций, потерянные строки, `Unexpected token`.
- **Причина:** файл 7,5 тыс. строк, вставки по индексам сдвигают всё ниже.
- **Лечение:** откат `git checkout -- src/index.html`, затем правка по уникальным строкам и `node --check` последнего `<script>`.
- **Не повторять:** не править по номерам строк без проверки; всегда вырезать последний `<script>` в `%TEMP%\tap-main.js` и проверять.

## PowerShell съедает `$()` внутри двойных кавычек

- **Симптом:** в JS попадает `zoomBtn` вместо `$('zoomBtn')`.
- **Причина:** интерполяция PowerShell в двойных кавычках.
- **Лечение:** одинарные кавычки или here-string с `@'…'@`.
- **Не повторять:** генерировать код только через одинарные here-string.
