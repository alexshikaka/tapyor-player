- [ ] По точности: точные совпадения названия наверху.
- [ ] Сначала бесплатные: YouTube/SoundCloud/Audius выше Яндекса.
- [ ] Для эфира: лайвы, каверы, видео > 10 мин — в конце.
- [ ] По площадкам: разделы в порядке из Настройки → Поиск (поменять ↑↓ и проверить).
- [ ] «+2 версии» у строки — список версий, любая играет.
- [ ] Выбор сохраняется после перезапуска; подгрузка при прокрутке и фильтры работают.
