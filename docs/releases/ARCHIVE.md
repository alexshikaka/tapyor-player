## Уровни

- **A — полный снимок:** `docs/releases/vX.Y.Z/` со всеми файлами (появится начиная с 0.19.1).

- **C — строка:** только запись в таблице ниже и ссылка на источник (TODO/HANDOFF).

## Где искать детали

1. `TODO.md` — хронология по версиям с замерами (самый подробный источник).
2. `docs/HANDOFF.md` — «История версий (кратко)».
3. Git-теги `v0.17.1`, `v0.18.0`, `v0.19.0` — код на момент релиза. Вся история git начинается с 0.17.1; более ранние версии жили до переинициализации репозитория и сохранились только в документах.
4. `docs/RELEASE-0.19.0.md` — текст релиза 0.19.0.
5. `C:\Users\user\Documents\tapyor-handoff` (вне репозитория) — старый комплект от 22.10: патч док-панели, `widget.html`, выгрузки переписки за 22.10. Не эталон, но полезен как источник по 0.18–0.19.

## Правило backfill

Если мы снова трогаем старую версию (например, разбираем регресс 0.15), то по ней создаётся папка `docs/releases/vX.Y.Z/` уровня B: README, CHANGES (из TODO), ссылки на тег и известные ошибки. Задним числом придумывать решения и проверки нельзя — только то, что подтверждается документами, git и перепиской.
