# Тапёр

Плеер для стримеров: музыка из Яндекс Музыки, YouTube, SoundCloud, Audius, Telegram; очередь-лента, «Моя волна», плейлисты, заказы за донаты, панель для OBS.

## Если ты нейросеть

Начни с `AGENTS.md` — там правила для любой модели и порядок чтения. Для Claude Code есть отдельный `CLAUDE.md`.

## Если ты нейросеть и тебя просят «провести аудит работы над программой»

1. Прочитай `docs/START-HERE.md` — это точка входа.
2. Затем `docs/AUDIT.md` — как делать аудит (три прохода) и что вернуть.
3. Отчёт пиши в `docs/audits/ГГГГ-ММ-ДД-твоё-имя.md`.
4. Ничего не публикуй, версию и `appId` не меняй.

Всё, что нужно, лежит в этом репозитории. Ничего не надо искать на чьём-то компьютере.

## Если ты владелец

Скажи модели:

> Проведи аудит работы над программой.

Дальше она сама прочитает `docs/START-HERE.md` и `docs/AUDIT.md`.

Если нужен релиз — скажи «собери релиз на гитхаб»: модель обязана выполнить `docs/RELEASE-CHECKLIST.md` без напоминаний, а не просто собрать установщик.

## Ветки

- `main` — релизная ветка и документы.
- `experiment` — текущая работа (может опережать `main`).

## Рабочие подробности

В репозитории есть рабочие подробности: пути на моём ПК, карточки сессий, переписка. Я работаю один и ссылку никому не давал. Если понадобится — их можно удалить: см. `docs/WORKING-DETAILS.md`.
